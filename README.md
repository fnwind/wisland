# Wisland · fnwind 的 fork

[Wisland](https://github.com/AsamiAkito/wisland) 的个人 fork：在原作者版本基础上修了安装、代理、面板开关、剪贴板展示等问题，并补了几个日常用起来更顺手的功能（一键重启、收起态资源监控）。

> 本 README **只记录这个 fork 相对上游的差异**。原始项目的完整说明（截图、原理、全部参数）请看[上游 README](https://github.com/AsamiAkito/wisland#readme)。

## 上游项目是什么

贴在屏幕边缘的液态毛玻璃胶囊（Windows 10 / 11，Python + PySide6）：与屏幕边缘以「表面张力」相连，按住能拖出拉丝、松手吸附回最近的边，悬停弹性展开。

| 能力 | 说明 |
| --- | --- |
| 收起态 | 时间天气 / 小形象 / 正在播放，滚轮切换；播放音乐时自动显示滚动歌词；消息、音量、股票提醒以动画浮现 |
| 小形象 | 发光双眼跟随鼠标，靠近时随机换表情，按压会被挤歪 |
| 音乐 | 网易云（读本地播放日志，无需插件）、QQ 音乐、Spotify、B 站 / 浏览器；歌词含翻译 |
| 主页 | 播放控制、展开方式、可穿透、静音、实时字幕、应用启动器 |
| 消息 | QQ / 微信 / 邮件提醒（读 Windows 通知与任务栏闪烁，不读消息正文） |
| 股票 | A 股 / 港股 / 美股行情与分时（腾讯财经公开接口） |
| 天气 | 多城市、逐小时与 5 天预报（默认 Open-Meteo，可换 OpenWeather） |
| 控制 | 音量、亮度、WLAN、蓝牙；检测到 Clash Verge 时显示代理控制 |
| 剪贴板 | 最近 10 条文字 / 图片，点击复制 |
| 翻译 | 日译中；实时字幕（系统声音 → 日语识别 → 翻译），点词查词、单词本、同步到 Anki |
| 主题 | 深色 / 浅色 / 胭脂撞色 / 晴空渐变 |

安装（上游方式）：装 [uv](https://docs.astral.sh/uv/) 或 Python 3.10+ → 双击 `setup.bat` → 双击 `wisland.vbs`。开机自启：右键灵动岛 → 开机自启。

## 这个 fork 改了什么（按天）

### 2026-11-17 · 首批改动（`6188bce`）

**安装**
- `setup.bat` 支持 uv：机器上没有 `py` 启动器、`python` 也不在 PATH 时同样能装完（此前会误报「未找到 Python 3.10+ 以上版本」），装好的 `.venv` 里 `pip` 照常可用。

**面板开关**
- 设置菜单新增「面板」子菜单：消息 / 股票 / 天气 / 控制 / 剪贴板 / 翻译 可逐项显示或隐藏，点一下即时生效，不用重启；主页固定显示。
- 关掉股票页后行情不再轮询、不弹涨跌提醒，重新打开立即恢复。
- 支持 `pages.hidden` 配置，手改 `config.json` 后「重新加载配置」同样生效。

**国内接口直连**
- 天气（含城市搜索）、网易云歌词、DeepSeek 翻译、实时字幕翻译默认不走系统代理，避免代理节点慢时出现「天气请求超时」。
- 天气可用 `weather.proxy` 单独选择：直连（默认）/ 跟随系统代理 / 指定代理地址。境外资源（识别模型、词典包下载）仍然走系统代理。

**稳定性**
- 修复「被任务管理器强杀 / 崩溃后再也启动不了」：不再被残留的锁文件卡住。

### 2026-11-17 · 剪贴板面板改为单行列表（`fa400f0`）

- 从 2 列卡片改为 40px 单行列表，一屏能看到 8 条（原来只有 2~3 张）。
- 左侧标记按类型区分：图片显示缩略图、颜色值（如 `#9CB9FF`）显示色块、文本显示三横线。
- 中间单行省略，多行内容标 `+N 行`；置顶记录常显图钉。
- 右端显示绝对时间：当天 `23:52`，同年 `11/14 23:53`，跨年 `2025/10/13 23:53`。
- 悬停整行高亮，右侧出现图钉 / 删除按钮。
- 鼠标停在缩略图上会弹出大图预览：最大 400×400、保持原始长宽比、小图不放大，距面板 20px；跟随「不参与截图」设置。
- 修复图片记录被当成文本的问题：PixPin 截图、浏览器里复制的图片现在都能识别成图片并显示缩略图；本地图片会另存一份，源临时文件被删也不影响；网络图片会下载后缓存。
- 记录里显示原图尺寸（如「图片 1280×720」）；颜色只在整串匹配时才算色块，正文里出现的 `#fff` 不会被误判。

### 2026-11-18 · 新增「重启 wisland」（`e5f1438`）

- 菜单（面板右键 / 齿轮按钮 / 托盘菜单）在「退出 wisland」上方新增「重启 wisland」，点一下完整重启，改完代码不用手动退出再启动。
- 拉起新实例失败时不会退出当前实例，只提示「重启失败，请手动重新启动」。
- 重启后保持原来的页签、面板显隐、窗口位置与剪贴板内容。

### 2026-11-18 · 收起态胶囊显示系统资源（`0fcb983`）

- 收起态在时间与天气之间显示 **CPU 占用、内存占用、网络上行 / 下行速率**，把原来的空白利用起来。
- CPU / 内存用圆环 + 百分比；占用 ≥80% 变橙、≥92% 变红，正常时跟随主题强调色。
- 速率自动换算单位（`512`、`12K`、`953M`）。
- 读数位置与每项宽度固定，数值变化时不会左右抖动，灵动岛本身也不会跟着伸缩。
- 可分别开关 CPU / 内存 / 网络（`compact.stats.*`），采样间隔可调（`compact.interval`，默认 1 秒）；全部关掉则保持原来的「时间 + 天气」布局。
- 自动轮换改为「键鼠空闲一段时间后才开始」：正在用电脑时一直保持监控态，停止操作满 60 秒后才按原规则在时间天气与小形象之间轮换（`island.auto_cycle_idle_s`）。

### 2026-11-18 · 修复重启后残留控制台窗口（`0a88e3d`）

- 连续点击「重启 wisland」不再留下多余的终端窗口。此前从第二次重启起会多出一个命令行窗口，关掉它灵动岛也跟着退出。
