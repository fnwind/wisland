# Wisland · fnwind 的 fork

[Wisland](https://github.com/AsamiAkito/wisland) 的个人 fork：在原作者版本基础上，修了日常使用中碰到的安装、代理、开关面板等问题。

> 本 README **只记录这个 fork 相对上游的差异**。原始项目的完整说明（截图、原理、全部参数）请看[上游 README](https://github.com/AsamiAkito/wisland#readme)。

## 上游项目是什么

贴在屏幕边缘的液态毛玻璃胶囊（Windows 10 / 11，Python + PySide6）：与屏幕边缘以「表面张力」相连，按住能拖出拉丝、松手吸附回最近的边，悬停弹性展开。

| 能力 | 说明 |
| --- | --- |
| 收起态 | 时间天气 / 小形象 / 正在播放，滚轮切换；播放音乐时自动显示滚动歌词；消息、音量、股票提醒以动画浮现 |
| 小形象 | 发光双眼跟随鼠标，靠近时随机换表情，按压会被挤歪 |
| 音乐 | 网易云（读本地播放日志，无需插件）、QQ 音乐、Spotify、B 站 / 浏览器；歌词含翻译 |
| 主页 | 播放控制、展开方式、可穿透、静音、实时字幕、应用启动器 |
| 消息 | QQ / 微信 / 邮件提醒（读 Windows 通知与任务栏闪烁，不读消息正文） |
| 股票 | A 股 / 港股 / 美股行情与分时（腾讯财经公开接口） |
| 天气 | 多城市、逐小时与 5 天预报（默认 Open-Meteo，可换 OpenWeather） |
| 控制 | 音量、亮度、WLAN、蓝牙；检测到 Clash Verge 时显示代理控制 |
| 剪贴板 | 最近 10 条文字 / 图片，点击复制 |
| 翻译 | 日译中；实时字幕（系统声音 → 日语识别 → 翻译），点词查词、单词本、同步到 Anki |
| 主题 | 深色 / 浅色 / 胭脂撞色 / 晴空渐变 |

安装（上游方式）：装 [uv](https://docs.astral.sh/uv/) 或 Python 3.10+ → 双击 `setup.bat` → 双击 `wisland.vbs`。开机自启：右键灵动岛 → 开机自启。

## 这个 fork 改了什么（按天）

### 2026-11-17 · 首批改动（`6188bce`，13 个文件 +304 / −36）

**安装 / 环境**
- `setup.bat` 优先使用 uv：`where uv` 命中就用 `uv venv` + `uv pip install` 建环境装依赖，机器上**没有 `py` 启动器、`python` 也不在 PATH 时照样能装**（此前会误报「未找到 Python 3.10+」）。
- 解释器按 3.12 → 3.13 → 3.11 → 3.10 → 3.14 依次尝试，uv 缺哪个会自动下载。
- uv 建的 venv 默认没有 pip，用 `ensurepip` 补上，`.venv\Scripts\pip` 照常可用。
- 新增 `UV_HTTP_TIMEOUT=60`：大包下载卡住时会失败并回退镜像，而不是无限等；若已设 `PIP_INDEX_URL` / `UV_DEFAULT_INDEX`，直接当镜像源用。
- 原来的 python.org 安装路径保留为 fallback，并额外扫描 uv 的解释器目录。

**界面**
- 设置菜单（右键灵动岛 / 导航栏齿轮）新增 **「面板」子菜单**：消息 / 股票 / 天气 / 控制 / 剪贴板 / 翻译 逐项打勾，**点一下即时显隐，不用重启**；主页是导航锚点，不可隐藏。
- 导航栏支持动态重建（`NavBar.set_items()`），弹簧动画、当前项、未读徽标都会保留；隐藏的页面只出栈不销毁，重新打开时数据是热的。
- 隐藏当前正在看的页面会自动回主页；关掉股票页时行情服务同步停止轮询（不请求、不弹涨跌提醒），重新打开再启动。
- 新增配置 `pages.hidden`，「重新加载配置」也会按它重排导航，手改 json 同样生效。

**网络（国内接口不再走代理）**
- 天气（含城市搜索）、网易云歌词、DeepSeek 翻译、实时字幕翻译全部改为**直连**，不再经过 Windows 系统代理。
- 原因：httpx 默认 `trust_env=True` 会通过 `urllib.getproxies()` 读注册表里的系统代理（Clash 的 `127.0.0.1:7897` 之类），节点一慢就变成「**天气请求超时**」。实测同一请求：直连 0.8~2.6s，走 Clash 2.6~5.2s 且抖动。
- 天气额外提供开关 `weather.proxy`：留空 = 直连（默认），`"env"` = 跟随系统代理，也可填具体代理地址；改完「重新加载配置」即生效。
- 仍会尝试系统代理的只剩境外资源：实时字幕识别模型下载（HuggingFace / hf-mirror）、词典包下载。

**稳定性**
- 修复「被任务管理器强杀 / 崩溃后**再也启动不了**」：残留的 `data/wisland.lock` 会让程序一直打印「wisland 已在运行」并退出。现在启动时按 pid 判断持锁进程是否还活着（僵尸锁则清掉重试）。

**仓库**
- 改为 fork + upstream 双远端结构（`origin` = 本 fork，`upstream` = 原作者）。
- `.gitignore` 增加 `.workbuddy/`；`config.json`（含 API Key）、`data/`（日志、剪贴板、单词本）本来就被忽略，不会进仓库。

### 2026-11-17 · 剪贴板面板改为单行列表（`fa400f0`，2 个文件 +392 / −98）

**为什么**：原来是 2 列卡片，卡片高度按宽度算（`width × 0.82`），640 宽的页面里每张 **257×211**，一屏只看得到 2~3 张，10 条记录要滚 3.4 屏。

**改成 40px 单行列表，一屏 8 条**：
- 左侧 20×20 标记：图片显示缩略图、颜色值显示色块、文本显示三横线符号。
- 中间单行省略；多行内容在尾部标 `+N 行`；置顶行常显小图钉。
- 右端绝对时间：当天 `23:52`，同年 `11/14 23:53`，跨年 `2025/10/13 23:53`。
- 悬停：整行浅色底 + 右侧出现图钉 / 删除（时间让位给按钮）。

**图片记录（顺带修掉的 bug）**：
- 之前 PixPin、浏览器「复制图片」的记录全都变成一串文本——它们给的是 `file:///C:/…png` 或图片 URL，而捕获逻辑是「有文本就存文本」，永远到不了图片分支。
- 现在按 **位图 → 本地图片文件 → 网络图片 URL** 三级识别，文本放最后：本地文件会另存一份进 `data/clips`（PixPin 的临时文件被删也不影响）；网络图片先走系统代理、失败再直连，都不行才退回文本。
- 条目里记录原图宽高，列表显示「图片 1280×720」。

**悬停预览**：新增 `ImagePreview` 浮层，等比缩放到不超过 400×400（小图不放大），贴着面板本体外侧 **20px**、与所在行垂直居中，右侧放不下自动翻到左侧；跟随「不参与截图」设置，换页 / 收起时自动隐藏。

**颜色识别**：要求整串匹配（`#RGB` / `#RGBA` / `#RRGGBB` / `#RRGGBBAA` / `rgb()` / `rgba()`），长文本里出现的 `#fff` 不会误判成色块。

### 2026-11-18 · 新增「重启 wisland」（`e5f1438`，3 个文件 +101）

菜单（面板右键 / 齿轮按钮 / 托盘菜单）在「退出 wisland」上方新增 **重启 wisland**：点一下先闪 400ms「正在重启…」，然后完整退出并重新拉起，改完代码不用再「退出 → 再双击启动」。「退出 wisland」与开机自启逻辑没有改动。

**为什么不能用「先启动新的、再退出旧的」**：`QLockFile` 的单实例锁在旧进程存活期间会拒绝新实例（打印「wisland 已在运行」后 `return 0`），全局热键和托盘图标也会撞。所以只能「后启动」。

**做法（等待者模式）**：旧进程用 `DETACHED_PROCESS | NEW_PROCESS_GROUP` 拉起 `run.pyw --restart-after <pid>`，这个进程先每 150ms 轮询旧 pid（上限 20s），等它消失后**自己变成新实例**继续启动——没有多余跳板进程，也不会抢锁。

- 新文件 `wisland/relaunch.py`：`wait_previous()` / `spawn_restart()`。
- `run.pyw`：解析 `--restart-after <pid>`，等完把参数清掉再走原启动流程（正常双击启动完全不受影响）。
- `app.py`：`restart_app()` 在 spawn 成功后才 `app.quit()`（走原来的 shutdown：停服务 → `cfg.save()` → `lock.unlock()`）；**spawn 失败时不退出**，只提示「重启失败，请手动重新启动」，避免「关掉了却起不来」。
- 重启后是收起态；页签、面板可见性、窗口位置、剪贴板都沿用退出前落盘的配置。

### 2026-11-18 · 收起态胶囊显示系统资源（`0fcb983`，6 个文件 +353 / −11）

**为什么**：收起态只有「时间 + 天气」，时间靠左、天气靠右，中间整片空白。现在把 **CPU / 内存 / 上下行速率** 放进这块空档，窗口宽度只从 150 加宽到 356。

**显示什么**：CPU、内存是圆环 + 百分比（≥80% 橙 `#EF9F27`、≥92% 红，其余用主题强调色）；网络是 `↑` / `↓` + 速率（`0 / 512 / 1.0K / 12K / 953M`，最长 4 个字符）。

**采样（新文件 `services/sysstat.py`，1Hz）**：`cpu_percent(None)` 0.03ms、`virtual_memory()` 0.026ms 放主线程直接采；`net_io_counters(pernic=True)` 约 3.5ms 交给后台线程，上一轮没回来就跳过。
- 不顺手启动已有的 `PerfService`：那个还有 GPU、磁盘、每核占用，对 34px 的胶囊太重。
- 两个坑：① 首次 `cpu_percent` 恒为 0%，先预热、300ms 后再出第一帧；② `net_io_counters` 会把物理网卡和 Clash TUN 一起累加，流量翻倍——只统计「在线 + 名字非虚拟 + 有物理 MAC」的网卡（`vgate0` / `Loopback` 没有 MAC，光按名字过滤会漏），采样间隔超过 5s（休眠唤醒）直接丢样本，避免跳出一个巨大瞬时速率。

**布局（改了 3 版才定）**：读者要求「读数不能因为数值变化而抖动」，所以不做「按实际宽度居中」：
- 读数起点固定在「时间 + 36px」，4 个槽位宽度全部按**最宽读数**预留（环 16 + 贴边 3 + `100%` 25 = 44；`↑` + 贴边 3 + `999M` 28 = 36），槽间距 8px，槽内左对齐。
- 这样 `3%` 与 `100%`、`0` 与 `953M` 占同样宽，圆环、数字、箭头、整块位置全部不动，只是槽内右侧留白多少不同；胶囊宽度用同一份数值算，岛本身也不伸缩。
- 顺带修掉 `fmt_rate` 的一个隐患：原来按 `v < 1024 * base` 分档，在 1M 附近会输出 `1024K`（5 字符），正好挤到下一槽；改成以 999.5 为界，输出恒 ≤4 字符。

**自动轮换**：原来固定每 30 秒在「时间天气 ↔ 小形象」之间切，监控态留不住。现在加 `island.auto_cycle_idle_s`（默认 60）：
- 键鼠空闲没满 60 秒就**一直保持监控态**并重新计时，用户一动就回到时间天气；
- 空闲满 60 秒后才按 `island.auto_cycle_s` 轮换；
- 自己用滚轮切过视图的，不再被自动轮换抢走（`compact.auto_view`）。

**配置**（`config.json`，也可在「重新加载配置」后生效）：
| key | 默认 | 说明 |
| --- | --- | --- |
| `compact.stats.cpu` / `.mem` / `.net` | `true` | 收起态显示哪几项；全关掉则不采样、胶囊回到原来的 150 宽 |
| `compact.interval` | `1.0` | 采样间隔（秒），限制在 0.5~10 |
| `island.auto_cycle_idle_s` | `60` | 键鼠空闲多久之后才开始自动轮换，`0` = 不判断空闲 |
